Chancery Instruction Builder

Generate deterministic Chancery settlement instructions and optionally wrap them in a Squads v4 vault proposal lifecycle.

Chancery schema Squads IDL
1

Settlement mode

Each mode prefills the instruction, its arguments, and the issued token mint.

2

Arguments

Integer values are raw decimal units. Byte arrays accept 0x hexadecimal.

3

Accounts

Known Chancery PDAs and program accounts are populated automatically. When wrapped, $SQUADS_VAULT resolves to the Squads vault.

4

Squads proposal

Optional. Leave unwrapped to export the bare instruction. The transaction index must be the next index expected by the multisig.

5

Transaction

Unsigned legacy transactions are compiled with the fee payer as first signer and zero-filled signature slots.

6

Generated output

JSON output contains account metas, instruction data, and unsigned transaction bytes.
